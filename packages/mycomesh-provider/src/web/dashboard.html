网络价格与产能

全网统一价：每天按前一天的利用率自动调整（最多 ±10%），像比特币难度一样。你的每日产能是约束性的：最多结算这么多，随真实成交增长。

陪审资格

满足全部条件后，你的 Provider 会被按成交额加权随机抽进陪审团，被抽中时自动用自己的模型判案并签名投票。
